# 📊 AI-Powered Trade Opportunity Analyzer

A high-performance **AI Engineer Task** developed for **AppScrip**. This FastAPI-based service conducts real-time market research on Indian industrial sectors and generates professional, strategic trade analysis reports using **Google Gemini AI**.

## ✨ Key Features

- 📡 Real-time Market Data: Scrapes latest trends using DuckDuckGo API  
- 🤖 AI-Driven Insights: Uses Google Gemini (1.5 Pro/Flash)  
- 🎨 Premium UI: Built with Tailwind CSS  
- ⏱️ Rate Limiting: 5 requests/minute using SlowAPI  
- 📊 Session Tracking: In-memory tracking  
- 🧱 Clean Architecture: Separation of main.py and logic.py  

---

## 🛠️ Tech Stack

Backend: Python, FastAPI  
AI: Google Gemini API  
Web Data: DuckDuckGo  
Frontend: HTML, Tailwind CSS, Marked.js  
Deployment: Render

## 📦 Setup (Copy-Paste Friendly)

Clone project:
git clone https://github.com/sravyasirapu/trade-opportunity-analyzer.git
cd trade-opportunity-analyzer

Install dependencies:
pip install -r requirements.txt

Set API Key:
export MY_API_KEY="your_gemini_api_key_here"

Run app:
python main.py

Open:
http://127.0.0.1:8000
